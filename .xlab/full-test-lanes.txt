# one pod each, in parallel. A lane installs and builds once, then runs its
# shards in order, every shard even after one fails.

# general_tests and verify_serialized_server matrices), run with the same
# commands (pnpm test:run:general / test:run:serialized). Upstream gives each
# its own 4-vCPU runner; a lane packs several because every pod pays for
